# Contributing

Thanks for considering a contribution.

1. Fork and create a feature branch from `main`.
2. Keep the change small and focused: one pull request per idea.
3. Run the suite before opening the PR: `python3 -m pytest -q`.
4. Do not commit virtual environments, caches or credentials.
5. Describe what changed and why in the pull request description.

Contributions are released under the MIT license of this project.
